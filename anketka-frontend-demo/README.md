# Anketka Frontend — демо-скелет

Это урезанная копия фронтенда Анкетки (панель онлайн-опросов): настоящая обвязка
проекта, но без бизнес-логики, трекинга и интеграций. Задача — ознакомиться с кодом, запустить проект локально, связать с демо бэкендом, попробовать сделать минимальную реализацию под новый хендлер на бэкенде.

### Генерация клиента

```bash
npm run gen:api
```

Нужны запущенный backend-demo и Java 11+: генератор — это jar, при первом запуске
он скачивается сам. Сгенерированный код лежит в репозитории и руками не правится —
только перегенерация.
